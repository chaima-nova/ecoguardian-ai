# ecoguardian-ai
> City Intelligence & Early-Warning System

EcoGuardian AI is a modern urban intelligence platform designed to continuously monitor heterogeneous city data streams, discover emerging spatial-temporal patterns without predefined assumptions, and surface evidence-based early warnings for urban and infrastructure management.

---

## ✨ Key Features

👁 WATCH: Continuous monitoring of multi-modal city data streams (satellite observations, infrastructure sensors, mobility flows, and environmental indicators).

🔎 DISCOVER: Automated discovery layer to identify anomalous spatial deviations and cross-system relationships that humans didn't explicitly ask for.

⚠️ WARN: Transparent, evidence-backed early warnings featuring strict epistemic labeling (`OBSERVED`, `DISCOVERED`, `INFERRED`, `HYPOTHESIZED`, `VALIDATED`).

🌐 LIVE 3D DIGITAL TWIN:** Interactive GPU-accelerated WebGL 3D urban canvas with live spatial layers powered by **Deck.gl** and **MapLibre GL**.

🎨 VIBRANT GLASS UI: High-contrast multi-tone blue glassmorphic user interface built for high-level decision support.

---

## 🛠️ Tech Stack

Frontend Framework: React 18/19, TypeScript, Vite
Styling & UI: Tailwind CSS, Custom Glassmorphism System
Geospatial & 3D Mapping: Deck.gl (`@deck.gl/react`), MapLibre GL JS
Icons & Components: Lucide React, Framer Motion
